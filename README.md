# Рабочая тетрадь React — ДЗ-08

Решения уроков 1–90 учебника https://code.mu/ru/javascript/framework/react/book/prime/.
Основа: https://github.com/atamanov-dmitriy/top-react-course.

## Запуск

```sh
npm ci
npm run dev
```

Проверки: `npm run build` и `npm run lint`.

## Публикация

В Settings → Pages выберите Source: GitHub Actions.
Workflow публикует ветку main. Адрес: https://Vlad-Vershinin.github.io/react-lessons/.
Навигация использует HashRouter, поэтому ссылки уроков работают на GitHub Pages.

Установка расширения React DevTools (урок 3) выполняется отдельно в браузере.

Предыдущая версия react-lessons сохранена в legacy/.
